CLOUD NATIVE / EP3

Flujo asíncrono de reservas

Arquitectura de mensajería entre ms-bookings, RabbitMQ y ms-notify.

Ver arquitectura
SOLICITADA

Reserva creada

Evento:

BOOKING_CREATED
ms-bookings → RabbitMQ → q.cmd.email → EmailConsumer
APROBADA

Reserva aprobada

Evento:

BOOKING_STATUS_CHANGED
RabbitMQ → EmailConsumer
RabbitMQ → q.cmd.prep → PrepConsumer
DEVUELTA

Reserva devuelta

Evento:

BOOKING_STATUS_CHANGED
RabbitMQ → EmailConsumer
RabbitMQ → q.cmd.voucher → VoucherConsumer
Gestión de errores y DLQ

Si un consumer rechaza un mensaje con NACK sin requeue, la configuración de RabbitMQ puede enviarlo a una Dead Letter Queue.
