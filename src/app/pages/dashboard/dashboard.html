Resumen operacional CampusLab

Autenticación corporativa

Inicio de sesión mediante Azure AD y MSAL Angular.

Rutas protegidas

Dashboard y reservas protegidas mediante MsalGuard.

Consumo seguro del backend

El frontend envía Bearer Token al BFF usando MsalInterceptor.

Microservicio de reservas

El BFF deriva solicitudes hacia ms-campuslab-bookings.

EP3

Integraciones Cloud Native

Arquitectura incorporada para mensajería asíncrona, persistencia cloud y administración de RabbitMQ.

RabbitMQ

Integrado

Mensajería desacoplada mediante colas, exchanges, bindings y routing keys.

ms-notify

Consumers

Procesamiento asíncrono de notificaciones, tickets de preparación y vouchers.

Dead Letter Queues

Configuradas

Manejo de mensajes que no pueden ser procesados mediante DLQ y confirmación manual.

AWS RDS

PostgreSQL

Persistencia cloud de reservas mediante PostgreSQL, JPA e Hibernate.

Rabbit Admin

REST API

Administración de colas, exchanges y bindings mediante un microservicio independiente.
